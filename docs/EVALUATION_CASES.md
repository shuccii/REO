# 追加評価課題 (0.16)

従来課題は強いモデルで検出が飽和しているため、正常な記述への誤検出、情報不足時の保留、部分対応、章間矛盾、模擬質疑の開始を追加しました。入力はすべて架空です。

- clean_short: 正しい記述統計と限定された主張を不当に誤り扱いしない。
- insufficient: 数値を捏造せず、必要な独立単位/原データ/デザインを求める。
- partial_pairing: 7/10の部分対応を独立群にせず、安易な完全ケース除外も避ける。計算したと報告するなら実行証跡を残す。
- cross_chapter: 数値と独立単位の章間矛盾、未知試料への一般化主張を照合。
- defense: 一問のみ質問して待ち、答えや途中フィードバックを先に示さない。これは最初の一ターンの評価であり、音声での待機や複数ターンの追従は評価しない。

benchの固定モデル・採点モデルを明示して、既存4課題と合わせて実行できます。追加課題の実モデル評価は未実施で、正答率や削減率の実績ではありません。開発時の回帰課題と分けた未使用課題・実原稿・専門家確認も引き続き必要です。
