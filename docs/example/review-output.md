## 指摘（重大なものから順に）

### 1. 【致命的】評価用データでハイパーパラメータを選んでいる（4.2, 9行目）
- **問題点:** 評価用データの R² が最大になるように選んだ時点で、評価用データは「モデル選択」に使われています。そのため R²=0.92 は、未知のデータに対する性能ではなく、偏った（高めに出る）推定です。評価用は約24件しかないので、偏りは無視できません。
- **修正案:**
  - 学習用データの中だけで交差検証してハイパーパラメータを選びます。
  - 評価用データは最後に1回だけ評価します。
  - できれば、入れ子の交差検証（外側で評価、内側で選択）にします。
  - 探索範囲と乱数シードも書きます。
- **修正できたと判断する条件:** 評価用データがモデル選択に一切使われていないことが、手順とコードで確認できること。そのうえで再計算した値で4.3を書き直してあること。

### 2. 【致命的】「未知の基質」という主張を検証する設計になっていない（4.2, 8行目 / 4.4, 15行目）
- **問題点:** 120件は基質15種×触媒8種の格子です。無作為に分けると、評価用の各基質は、別の触媒との組み合わせでほぼ確実に学習用にも入っています。測れているのは「既に見た基質の、見ていない組み合わせ」の予測（内挿）です。
- **追加の問題:** 説明変数に**基質そのものの情報が入っていません**（触媒・温度・時間・溶媒・塩基のみ）。基質の情報なしで R²=0.92 になるなら、別の説明が考えられます。文献では基質ごとに特定の条件が使われやすいため、条件が基質や出典を間接的に表している（代理変数になっている）可能性です。
- **修正案:**
  - 基質単位で分ける交差検証（Leave-one-substrate-out や GroupKFold）を行い、基質ごとの誤差を示します。
  - 新しい触媒に対する予測も主張するなら、触媒単位で分ける検証も行います。
  - 基質を記述子で表すのか、表さないのかを明記します。
- **修正できたと判断する条件:** 基質単位の検証結果が示され、その値に見合う表現に結論が直されていること。性能が大きく下がった場合は、「既知の基質の組み合わせの補完」と主張を狭めれば十分です。それも正当な成果です。

### 3. 【重大】特徴量重要度から「Pd-X で収率が上がる」と結論している（4.3–4.4）
- **問題点:**
  - 特徴量重要度は「予測にどれだけ効いたか」の大きさを示すだけで、収率を上げる方向か下げる方向かは分かりません。
  - さらに、学習済みモデルの性質であって、因果関係ではありません。
  - ランダムフォレストの不純度ベースの重要度は、one-hot変数や相関した変数で偏りやすいことも知られています。
- **代わりの説明:**
  - Pd-X が使われた反応だけ、条件（温度・塩基・溶媒）が良かった。
  - Pd-X のデータが特定の出典（自研究室で最適化済みの系、または高収率だけが報告された文献）に偏っている。
- **修正案:**
  - 評価用データで permutation importance を計算し、部分依存（PDP/ICE）で効く方向を示します。
  - 同じ基質・同じ条件で触媒だけを変えたペアを集めて比較します。
  - 最も強い根拠になるのは、少数の基質で触媒だけを変え、独立に反応を繰り返す対照実験です。
  - それができない場合は、表現を「モデルは Pd-X の有無を予測に強く利用していた」に弱めます。
- **修正できたと判断する条件:** 因果を示す表現を、条件をそろえた比較か対照実験で裏づけていること。裏づけがない場合は、表現が予測への寄与にとどめてあること。

### 4. 【重大】繰り返しが「同じ液の3回測定」だけで、反応自体の再現性が分からない（4.2, 7行目）
- **問題点:** 3回測定でつかめるのは分析のばらつきだけです。反応を独立にやり直したときのばらつき（仕込み、ロット、日による違い）は含まれていません。このばらつきが分からないと、R² の上限（ノイズの天井）も、「高精度」かどうかも判断できません。
- **追加の確認:**
  - 収率の定義が出典によって混在していないか（単離収率か、GC/NMR収率か）。
  - 何を基準にした収率か（限定試薬）。
- **修正案:**
  - 代表的な数条件で独立に2〜3回反応をやり直し、反応ごとのばらつき（SD）を推定します。
  - モデルの誤差（MAE、%単位）をそのばらつきと比べます。
  - データ表に収率の定義と出典の列を加えます。
- **修正できたと判断する条件:** 反応ごとのばらつきの推定値と収率の定義が本文に明記され、モデル誤差との比較が示されていること。

### 5. 【重大】文献データと自研究室データの出典効果、文献の選択バイアス
- **問題点:**
  - 文献は高収率の結果ばかりが報告されやすく、失敗例が欠けています。
  - 出典ごとに収率の分布や条件の範囲が違うと、モデルが出典の違いを覚えている可能性があります。
- **修正案:**
  - 出典別の収率分布を示します。
  - 出典単位で分ける検証（文献で学習して自研究室データで評価する、など）を行います。
  - 出典を変数に入れた場合と入れない場合を比べます。
- **修正できたと判断する条件:** 出典をまたいだ評価の結果が示され、出典効果が性能を説明しているかどうかについて結論が書かれていること。

### 6. 【中】比較対象（ベースライン）と不確かさの記述がない（4.3）
- **問題点:**
  - 約24件に1回分割しただけの R² は、分割の仕方で大きく変わります。
  - 格子データでは、「基質平均＋触媒平均」のような単純な足し算モデルでも R² が高く出る可能性があります。
  - 「高精度」の基準も決められていません。
- **修正案:**
  - 平均値予測、触媒ごとの平均、基質＋触媒の足し算モデル、線形回帰を比較対象にします。
  - 分割を繰り返した交差検証の平均とばらつき、ブートストラップ信頼区間、MAE（%単位）を報告します。
  - 4.1 で成功基準を定義します（例: 反応ごとのばらつき程度の誤差、または条件を選ぶのに十分な順位の正しさ）。
- **修正できたと判断する条件:** 比較対象との差と不確かさが同じ評価条件で並べて示され、事前に決めた成功基準に照らして結論が書かれていること。

### 7. 【中】再現できる記述になっていない（4.2）
- **問題点:**
  - 溶媒と塩基をどう表したか（one-hotか記述子か）が書かれていません。
  - 温度・時間の単位、欠けている値の扱いが不明です。
  - ハイパーパラメータの探索範囲、乱数シード、ライブラリのバージョンがありません。
  - 文献データの出典一覧と、データの抽出基準がありません。
- **修正できたと判断する条件:** 第三者が付録のデータ表とコードだけで数値を再現できること。

### 8. 【中・抜粋のため参考】先行研究との位置づけ
- **問題点:** 抜粋には先行研究との比較がありません。
- **修正案:** 例えば次のような研究に対して、本研究で新しく分かることを述べてください（引用前に原典を確認してください）。
  - 反応収率予測の先行研究と、ハイスループット実験（HTE）データを使った研究。
  - 文献の収率データの偏りを論じた研究。
  - 「ランダムな特徴量でも高い精度が出る」ことを示した批判的な研究。
- **修正できたと判断する条件:** 最も近い先行研究との違い（データ、評価の設定、得られた知見）が1段落で示されていること。
