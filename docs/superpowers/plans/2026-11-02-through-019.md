# Re.O through 0.19 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** bounded execution, offline mechanism comparisons and verified restart.
**Architecture:** standard-library execution engine and CLI, existing hash ledger,
separate offline benchmark study module; one final independent branch review.
**Tech Stack:** Python 3.12+, unittest, existing plugin manifests.
**Spec:** docs/superpowers/specs/2026-11-02-through-019-design.md

## Global Constraints

- No live model evaluations or new dependencies; no push/publication/activation.
- Unknown is not zero; Quick retains mandatory independent review.
- Resource limits cannot guarantee provider spending inside opaque commands.

## Review Focus

- Interrupted commands and surviving children must not silently spend on restart.
- Review evidence must cover current outputs and distinct host-declared actors.
- Input/output/checkpoint aliases and symlinks must not overwrite inputs.
- Failed observations count toward spending; null measurements stay unknown.
- Changed context, command or transitive evidence must invalidate reuse.
