# v0.3 contract reference

The plugin root contains dependency-free schemas and validators:

- `assets/task-manifest.schema.json` and `scripts/validate_task_manifest.py`
- `assets/task-result.schema.json` and `scripts/validate_task_result.py`
- `assets/research-contract.schema.json` and `scripts/validate_research_contract.py`

Use `assurance_profile: standard` with `research_contract: null` for ordinary work. Use `research_strict` for research, analysis, machine learning, statistics, scientific interpretation, optimization, or research reporting. A strict manifest names a normalized research-contract path relative to the manifest directory.

Validate from the plugin root:

```bash
python3 scripts/validate_task_manifest.py --json runs/<run-id>/tasks.json
python3 scripts/validate_research_contract.py --json --manifest runs/<run-id>/tasks.json runs/<run-id>/research-contract.json
python3 scripts/validate_task_result.py --json --manifest runs/<run-id>/tasks.json runs/<run-id>/*/result.json
```

Strict research contracts retain sample/group split assignments, transform fit scopes, synthetic-sample parents, selection-data boundaries, raw-prediction references, repeated-evaluation settings, baselines, data-quality evidence, and reproduction hashes. The validator rejects group overlap, fitting on non-training samples, resampling outside training, test-driven selection, nominal-label distance objectives, and unsupported prospective claims.

Research completion also requires claim-to-evidence mappings, passed research gates, a reproduction bundle, full-scope independent semantic review, and distinct observed worker/reviewer identities. A failed upstream validity gate invalidates dependent metrics, interpretations, explanations, optimizations, figures, and claims; preserve unaffected audit artifacts and return a constructive finding with correction, rerun scope, and acceptance condition.

The result validator returns 0 for valid inputs, 1 for contract failures, and 2 for invocation/internal errors. Archive-only legacy input is never integration eligible. Artifact paths are normalized relative paths; absolute paths, parent traversal, and symbolic links are rejected.
