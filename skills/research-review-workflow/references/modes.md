# Review modes

Mode controls depth and output, never truthfulness or scientific validity requirements.

| Mode | Reading | Output | Escalation |
|---|---|---|---|
| Quick | Requested excerpt/claim plus necessary dependencies | Scope, supported points, prioritized findings with evidence/correction/acceptance, unknowns, next action | Expand for central-claim risk and contradictions; disclose unread scope |
| Standard (default) | Whole requested material, rubric, phase, 1–2 relevant probes | Existing output-template in its fixed order | Add calculation or independent review where warranted |
| Deep | Standard plus cross-artifact tracing, alternative explanations and required independent review | Same readable template; retain detailed evidence separately | Stop dependent conclusions when evidence invalidates them |

Quick is appropriate for a targeted question, not an undisclosed shortcut for a full review. A numerical error still requires an executed calculation. For an interactive defense, use one question at a time; do not print the full report template at each turn. Budget/usage is observable only when the host reports it; do not replace token counts with turns. If a hard budget cannot be observed, report that limitation.
