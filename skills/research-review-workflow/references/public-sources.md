# Public source index

Evidence checked on 2026-09-30. This is a starting set for retrieval, not an exhaustive bibliography. The operational rubric/probes are a synthesis; no source validates the plugin or grants faculty authority. Retrieve the current relevant source when using it. A `partial` source below must not be represented as fully read in review reports.

| Source | Access verified in this upgrade | Operational use and limit |
|---|---|---|
| [NAIST degree criteria](https://www.naist.jp/campuslife/degree/criteria.html) | Public page body read | Master's assessment: background/objective, method scrutiny, organization/analysis of results, logical conclusions, scholarly writing and ethics; novelty/usefulness emphasized. Actual rubric is linked to the educational-record system and was not inspected. No public numeric passing threshold inferred. |
| [NAIST materials degree-criteria PDF](https://www.naist.jp/publish/files/busitu_sinsa_kijun.pdf) | Both pages read from official download; PDF metadata dated 2016, title indicates H27/2014 update | Historical field-specific seven-item criteria include knowledge/literature and oral presentation. PDF states separate 100-point assessments with 60-point thresholds; applicability to a current student was not established. Compare current program documents before using thresholds. |
| [REFORMS author project](https://reforms.cs.princeton.edu/) | Public project body and primary paper extract read | Eight modules / 32 items for scientific goals, reproducibility, data, preprocessing, models, leakage, metrics/UQ and generalizability. Use relevant items with locators, not a universal mechanical pass score. |
| [DARPA Heilmeier Catechism](https://www.darpa.mil/about/heilmeier-catechism) | Public body read | Operationalize goal, alternatives, contribution, beneficiaries, risk, cost, time and milestone tests. Research-program tool, not thesis eligibility. |
| [NeurIPS 2026 reviewer guidelines](https://neurips.cc/Conferences/2026/ReviewerGuidelines) | Public body read | Quality, clarity, significance/originality and constructive review. ML conference expectations do not replace degree/program criteria. |
| [NeurIPS paper checklist](https://neurips.cc/public/guides/PaperChecklist) | Public body read | Scope/limitations, assumptions, reproducible details and meaning of uncertainty/error bars. Apply conditionally to relevant methods. |
| [ASA p-value statement](https://www.amstat.org/docs/default-source/amstat-documents/p-valuestatement.pdf) | Partial: PDF accessible; six principles/extract inspected, not full close reading | Effect and scientific context matter; p-values are not effect magnitude or probability that a hypothesis is true. Statistical significance is not a standalone validity gate. |
| [Probing OOD generalization in materials](https://arxiv.org/abs/2406.06489) | Partial: author-preprint abstract/search record inspected | Distinguish nominal chemistry/structure holdouts from representation-space novelty. Findings concern studied tasks, not universal OOD failure. |
| [Materials dataset redundancy control](https://arxiv.org/abs/2307.04351) | Partial: author-preprint abstract/search record inspected | Near-duplicate/similar-material contamination and realistic evaluation. Similarity definitions must fit the domain. |
| [Learning properties from multi-fidelity data](https://arxiv.org/abs/2005.04338) | Partial: author-preprint abstract/search record inspected | Abstract and limited Methods search extract; full PDF retrieval failed. Compare fidelity-specific and integrated information; specific empirical improvements do not guarantee universal benefit. |
| [Calibration after bootstrap](https://arxiv.org/abs/2105.13303) | Partial: author/public-manuscript abstract/search record inspected | Ensemble dispersion may require calibration against errors. Check applicability and held-out calibration. |
| [Interpretability for materials science and chemistry](https://pubs.acs.org/doi/10.1021/accountsmr.1c00244) | Partial: publisher search extract only | Retrieval lead for model explanations versus mechanism; obtain full relevant text before detailed attribution. |
| [NIST measurement uncertainty reference-materials publication](https://www.nist.gov/publications/evaluating-expressing-and-propagating-measurement-uncertainty-nist-reference-materials) | Partial: official publication record only | Retrieval lead for measurement-uncertainty definitions/propagation; full technical procedures not verified here. |
| [COPE ethical reviewer guidance](https://doi.org/10.24318/2019.1.4) | Partial: search record; full guidance retrieval failed | Retrieval lead for unbiased constructive review, confidentiality and conflicts. Do not claim full guidance was inspected. |

Private Slack teaching examples and laboratory policies are deliberately maintained as user-local references. Historical local conventions cannot be generalized to other institutions, seminars or projects.
