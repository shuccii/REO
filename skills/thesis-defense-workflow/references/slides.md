# Track S: slides and script

Institution or laboratory templates and rules override this guide.

## Design backward

Plan in this order: purpose → conclusion → the minimum results that convince a skeptical committee member → only the methods needed to trust those results. Do not follow the chronological order of the work, and do not put every result in the talk. Everything removed becomes a candidate backup slide.

A starting allocation for the main talk: background and objective about 10–15%, methods about 10–15%, results and discussion about 60–70%, conclusion and outlook about 10%. Adjust after timing a rehearsal.

## Slide checks

| Check | Done when |
|---|---|
| Time budget | At most about one slide per minute; measured rehearsal time within the limit with margin |
| Roadmap | An outline slide after the title tells the listener the route |
| One message per slide | The slide title states the message; no slide carries two topics |
| Flow | Each slide answers a question raised by the previous one |
| Figures | Axes, units, symbols and conditions explained aloud; the takeaway written on the slide |
| Text | Short phrases, not full sentences; what is shown is spoken and what is not spoken is removed |
| Readability | Sans-serif font; body text large enough to read from the back (often 20 pt or more); checked on the venue projector if possible |
| Color | Dark text plus a small number of accent colors used only for emphasis; distinguishable without color where it matters |
| Aspect ratio | Matches the venue display; if unknown, check both or ask |
| Slide numbers | On every slide, so examiners can refer to them |
| Claims | Every quantitative claim maps to a thesis page or figure; wording matches evidence strength |
| Conclusion and outlook | Findings and their scope, not a list of activities; limitations and future work distinct; a broader outlook on what the result means for the field |
| Criteria | Each institutional criterion is visible somewhere in the talk |

## Backup slides

Prepare backup slides for predictable deep questions: the principle of every key method or instrument, detailed comparison with the closest prior work, preliminary and failed experiments, parameter choices and sensitivity, additional controls, and the data and code locations. Number them and keep an index for fast navigation during Q&A.

## Script

Write a script per slide, then cut it to fit the measured time. A speaking rate the audience can follow (for example about 120–150 English words per minute) is a starting point; the rehearsal decides.
